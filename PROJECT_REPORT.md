Cybersecurity work often begins with information gathering. Footprinting and reconnaissance are used to identify publicly exposed information and understand the digital environment surrounding a target or learning scenario. Network scanning extends this process by evaluating reachable systems and exposed services, provided the task is performed within an authorized and controlled scope.

This repository reflects such a learning exercise. It contains visual evidence in the form of screenshots, along with supplementary documentation, which provide the basis for understanding the work completed. ## 5. Methodological Context
A standard professional workflow for footprinting, reconnaissance, and network scanning includes the following phases:

1. Define the scope and authorization boundary.
2. Gather publicly observable information in a controlled manner.
3. Identify exposed assets and visible service information.
4. Perform network scanning only within the approved environment.
5. Record findings with screenshots and supporting notes.
6. Prepare a clear report with evidence, limitations, and conclusions.

This repository aligns with that workflow by collecting visual evidence and documenting the assignment in a structured way. The project emphasizes documentation and evidence-handling, which are essential elements of cybersecurity reporting and professional assessment.
